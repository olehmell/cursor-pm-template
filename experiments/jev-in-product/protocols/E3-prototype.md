# Protocol E3 — Prototype critique

## Product decision
Does a screen advance the stated hypothesis, and is the primary CTA clear?

## Judgments
1. `advances_hypothesis` (noul) — state includes hypothesis + screen purpose
2. `cta_clarity` (score)

## Dataset
- Source: PetID screen list from `usecases/03-prototyping/`
- Unit: screen description / copy snippet
- Target: all 8 screens + a few negative controls

## Metrics
Agreement with gold; usefulness for “what to redesign next”
